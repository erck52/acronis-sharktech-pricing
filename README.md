## 真实成本怎么算：超额计费的口径最容易看错

四档价格表里藏着一个容易被带偏的点：超额存储的单价按周期列出来是「周期越长越贵」（$0.02/GB 月付 vs $0.12/GB 年付），一些推荐文章据此得出「月付超额最便宜」的结论。这个比较方式有误导性，因为月付的超额费按月收，年付的超额费按年收，口径不同。

换成同一口径（每 GB 每月）再算一遍：

- 月付：$0.02/GB/月
- 季付：$0.04 ÷ 3 ≈ $0.0133/GB/月
- 半年付：$0.06 ÷ 6 = $0.01/GB/月
- 年付：$0.12 ÷ 12 = $0.01/GB/月

按官方标价直接换算，长期档的超额单价折算后更低。举个例子，备份量稳定在 500GB（即超出基准 300GB）的场景，月付一年花费是 $4×12 + 300×$0.02×12 = $120；年付则是 $24 + 300×$0.12 = $60，同样的存储量按标价算正好省一半。

不过这里要加一个限定：官方博客公布的年付档（$24/年、超额 $0.12/GB）与月付档的差额幅度偏大，档位之间的比例并不寻常，以上数字是官方标价的直接换算，不代表结账页的最终金额。下单前以购物车逐项明细确认实际价格，尤其是选年付的时候。
